# Kinza

The current client site is **V5**: https://m-adib.github.io/kinza-demo/v5/

## Website versions

| Folder | Purpose |
| --- | --- |
| `v5/` | Current client website |
| `v6/` | Experimental cinematic option |
| `v4/`, `v3/`, `v2/` | Earlier design options |
| `index.html` | Original V1 design |
| `docs/` | Historical design notes |

Each version keeps its existing public URL. Each page contains its own HTML, styles and JavaScript. There is no build step.

## Original source material

`source-materials/` exists in the main local Kinza folder and is excluded from Git and publication.

| Folder | Contents |
| --- | --- |
| `source-materials/briefs/` | Landing page brief and reference HTML |
| `source-materials/brand/` | Brand guidelines, palette, label artwork and source logo |
| `source-materials/videos/` | Original horizontal and vertical video deliveries |
| `source-materials/archives/` | Original ZIP deliveries and chat exports |
| `source-materials/references/` | Other-brand visual references |

Private tool scripts and session notes remain in `.claude/`. All retained files keep their contents. Earlier site versions and their media remain available.
